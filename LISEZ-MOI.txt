MA CAVE À VIN — fichiers pour GitHub Pages

Téléversez à la racine du dépôt les fichiers suivants : index.html, manifest.json, icon.svg et sw.js.
Ne téléversez pas vos données de cave ou le fichier de sauvegarde JSON : les données personnelles restent dans le stockage local du navigateur.

La sauvegarde JSON contient l'inventaire et les photos que vous avez ajoutées. Conservez-la dans un endroit privé.
Attention : vider les données du navigateur peut supprimer la cave locale. Exportez régulièrement une sauvegarde.
